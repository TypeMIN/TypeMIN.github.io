# typemin.github.io

TypeMIN 개인 브랜드 사이트 — [typemin.github.io](https://typemin.github.io)

Astro 5 + GitHub Pages로 만든 개발/사진/음악/글 기록 공간.

## 기술 스택

- [Astro 5](https://astro.build) — 정적 사이트 생성
- GitHub Pages + GitHub Actions — 자동 배포
- Pretendard + JetBrains Mono — 폰트

## 개발

```sh
npm install
npm run dev
```

## 배포

`main` 브랜치에 push하면 GitHub Actions가 자동으로 빌드 & 배포합니다.
