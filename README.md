# TypeMIN GitHub Pages

`TypeMIN.github.io`용 개인 GitHub Pages 사이트입니다.

## 배포 방법

1. 저장소 이름이 `TypeMIN.github.io`이면 루트 주소에 배포됩니다.
2. `main` 브랜치에 푸시합니다.
3. GitHub 저장소 설정의 `Pages`에서 배포 브랜치가 `main` / `/(root)`로 되어 있는지 확인합니다.

## 수정 포인트

- `index.html`: 소개 문구, 버튼 링크, 이메일 주소
- `styles.css`: 색상, 레이아웃, 카드 구성
