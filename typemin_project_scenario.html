1
GitHub 저장소 + 로컬 환경 세팅
30분
GitHub 저장소 생성
github.com → New repository → 이름: typemin.github.io
Settings → Pages → Source: GitHub Actions 선택
Astro 프로젝트 생성
npm create astro@latest typemin.github.io
# 템플릿: blog
# TypeScript: Yes (strict)
# git init: Yes
cd typemin.github.io
npm install
원격 저장소 연결 + 첫 push
git remote add origin https://github.com/TypeMIN/typemin.github.io.git
git add .
git commit -m "feat: init Astro project"
git push -u origin main
2
GitHub Actions 배포 설정
10분
.github/workflows/deploy.yml 생성
name: Deploy to GitHub Pages
on:
  push:
    branches: [main]
  workflow_dispatch:
permissions:
  contents: read
  pages: write
  id-token: write
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: withastro/action@v3
astro.config.mjs 설정
import { defineConfig } from 'astro/config';
export default defineConfig({
  site: 'https://typemin.github.io',
});
배포 확인
push 후 2~3분 → GitHub Actions 탭 확인 → https://typemin.github.io 접속
