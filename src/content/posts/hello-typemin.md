## 시작하며

**만들고, 기록하고, 탐색합니다.**

이 사이트는 제가 배우고, 만들고, 경험하는 것들을 기록하는 공간입니다.

## 앞으로 담을 것들

- **Dev** — 개발 공부하며 배운 것, 만들어본 것
- **Photo** — 카메라를 들고 다니며 담은 순간들
- **Music** — 만들고 있는 음악, 들으며 느낀 것들
- **Writing / Essay** — 생각나는 것들, 읽은 것들

코드 블록도 잘 보이는지 확인:

```typescript
const typemin = {
  name: 'TypeMIN',
  motto: '만들고, 기록하고, 탐색합니다.',
  interests: ['dev', 'photo', 'music', 'writing'],
};
```

앞으로 꾸준히 채워나갈 예정입니다.
